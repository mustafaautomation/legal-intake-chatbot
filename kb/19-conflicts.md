## How the conflict screen works

Before a consultation is offered, the desk compares the names you type with a small mock client list. A match stops the chat so a person can review it. This is a preliminary screen, not a formal conflicts opinion. The demo list includes names such as Dana Whitfield and Northline Logistics LLC. A similar-sounding name is not a match.
